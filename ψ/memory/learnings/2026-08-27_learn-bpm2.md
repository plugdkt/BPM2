# Learned BPM2

- Budget tracking system for MEDSCI (คณะวิทยาศาสตร์การแพทย์ ม.พะเยา): real-time allocation/spend/transfer per department, PHP 8.2 + MariaDB, IIS deploy, SSO-only login (MEDSCI ACC) — no local passwords ever stored.
- Balance is always computed live from `bpm_line_item_balance()` — never cached/stored — treated as the single source of truth across dashboard, reports, and transfer approval re-validation.
- Thai PDF export requires `Options::isRemoteEnabled=true` + `setChroot()` scoped to the fonts dir, or Dompdf's `registerFont()` silently fails and falls back to Helvetica (tofu boxes for Thai text) with no error.
